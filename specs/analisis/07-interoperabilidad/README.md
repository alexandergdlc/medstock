# Interoperabilidad: espacio de análisis reservado

Esta carpeta organiza la futura documentación de interfaces. La reorganización
no añade requisitos ni implementa integraciones.

El [alcance vigente](../01-contexto/03-alcance-y-limites.md) mantiene los pagos y
la facturación fuera del sistema y no confirma una API de terceros. El análisis
de alternativas sencillas y gratuitas se preparará en un PR separado: intercambio
CSV para compras y exportación de movimientos, y sistema externo de demostración
para solicitudes. La identidad corporativa queda como evolución por evaluar.
No hay contratos detallados, conexiones reales ni servicios de pago habilitados.

Volver al [índice de análisis](../00-indice-y-estado.md).
